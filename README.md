# ISO/IEC 27001:2022 ISMS Implementation - SecurePay Technologies (Simulated)

> **Simulated portfolio project.** SecurePay Technologies Pvt. Ltd. is a fictional organisation. Nothing here claims real certification or legal compliance.

A GRC portfolio project that builds an ISO/IEC 27001:2022-aligned ISMS for a fictional 50-person FinTech/SaaS company (AWS, Microsoft 365, GitHub, PostgreSQL, CRM, HR/payroll SaaS).

## Lifecycle
Context -> Scope -> Assets -> Risk Assessment -> Risk Treatment -> Control Mapping -> SoA -> Policies -> Gap Assessment -> Internal Audit -> Corrective Actions -> Management Review -> Continual Improvement

## Traceability
`Asset (02) -> Risk (03) -> Treatment (03) -> ISO control (04) -> Evidence (07) -> Audit result (07) -> Corrective action (08) -> Management review (09)`

## Contents
| Folder | Contents |
|---|---|
| 01-ISMS-Scope | Scope statement, internal/external issues, interested parties, legal and regulatory obligations |
| 02-Asset-Management | 20 assets with owner, classification and C/I/A scoring (criticality = MAX by formula) |
| 03-Risk-Management | 5x5 methodology, 18-risk register with residual scoring, treatment plan |
| 04-ISO-Controls | Risk-to-Annex A mapping; Statement of Applicability for all 93 controls |
| 05-Policies | 7 policies with document control |
| 06-Gap-Assessment | Current vs target state and severity |
| 07-Internal-Audit | Checklist, findings, evidence register |
| 08-Corrective-Actions | Root cause, action, owner, deadline |
| 09-Management-Review | KPIs and management decisions |

## Headline numbers
18 risks (1 Critical, 17 High) reduced to Medium or below after treatment | 93 Annex A controls assessed for applicability | 4 audit findings with corrective actions

## Skills demonstrated
Governance, risk management, ISO 27001 clause and Annex A knowledge, audit evidence, corrective action, management reporting.

## Limitations
Fictional company, simulated evidence and KPIs. Legal obligations are identified, not assessed. Not a certification claim.
